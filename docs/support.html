Offline Saved Areas

Version 1.0 saved areas prepare Fletcher historical map tiles. Apple basemaps, Nova Scotia aerial imagery, and restricted provincial reference layers remain online services, though recently viewed tiles may stay available from cache.

Reference Layers

Provincial layers and historical maps are context layers. They are not suitable for legal property decisions, surveying, title research, emergency use, flood-risk assessment, or route guidance. Always confirm important decisions with the official source.

Current Location

The Current Location button asks for permission only when you use it. You can change that permission any time in iOS Settings. You can also mark a point or save a foreground track locally on the device; leaving the app pauses a recording.

My Maps

On layers you draw, you can add freeform attributes and photos. A KMZ export can carry those photos; they stay on the device unless you export them.

Data Sources And Licenses

Open the in-app Data Sources & Licenses screen for attribution, layer caveats, and source links. This transparency screen is the best first stop if a layer looks incomplete, delayed, or different from an official record.

The Web Map

The browser version at kinnokilabs.com/map shares its data sources with the app. It can record a foreground track and save it as a local layer; location permission is still requested only when you use the location controls. For web-map questions, corrections, or feedback, email map@kinnokilabs.com.
