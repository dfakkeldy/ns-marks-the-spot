Built for curious feet

Every slider pull is a little time travel.

NS Marks The Spot turns archival Nova Scotia maps into a practical companion for walks, research trips, and weekend detours. Fade between the old map and the current map to trace where a road bent, where a shoreline shifted, or where a name survived.

Fletcher overlay

Why it lands

Made for maps that do not behave like ordinary screenshots.

01

Georeferenced history

Twenty-four Fletcher sheets, each georeferenced and clipped, sit over the modern map. The alignment is honest: a sheet can sit a few hundred metres off modern ground, and the layer says so.

02

Instant transparency

A dedicated overlay control makes comparison feel tactile, fast, and readable.

03

POI discoveries

Waterfalls and other points of interest can appear as clean vector layers.

04

Offline-first tiles

Disk and memory caching keep panning smooth when the best places have weak signal.

No install needed

Use it in your browser.

The same Nova Scotia map runs as a web app on any phone, tablet, or desktop — parcel search, tax-sale notices, reference layers, and the historical overlays, no App Store required.

Open the web map
Open-source cartography

SwiftUI and MapKit on iPhone. React, Leaflet, and MapLibre in the browser.

The code is MIT licensed and structured around a map-engine boundary, so the interface can stay steady while the renderer evolves. Map imagery keeps its own licences and attribution, layer by layer.
