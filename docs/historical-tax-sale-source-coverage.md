# Historical tax-sale source coverage

Retrieved and reviewed July 19, 2026. Only official municipal primary sources
were used. Text extraction supported reconciliation; PIDs and financial values
in all fourteen included notice/result PDFs were also checked against rendered
pages. Tender terms independently confirmed the sale method for six events.
Public data and screenshots omit assessed-owner and bidder names.
