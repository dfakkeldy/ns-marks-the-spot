# Elected-representative contact directories for Nova Scotia — verified 2026-09-12

Scope: where to get CURRENT contact details for the MP, MLA, municipal mayor/warden + councillor, and CSAP school-board member for any NS point. The app does point-in-polygon locally; this note is about the *directory keyed by district id/name*, its fields, licence and refresh story. Everything marked VERIFIED was fetched live with curl (Chrome UA) on 2026-09-12; raw responses are in `scratchpad/research/`. Anything not verified is labelled.

Companion files (scratchpad/geo/):
- `reps_point_sample.json` — raw Represent API response for `/representatives/?point=44.74,-65.51` (Annapolis Royal).
- `reps_directory_sample.json` — hand-verified office contacts for the sample officials (see section 8).
- `ns_ed2026_districts.json` — the 56 current provincial districts (ED_NO, ED_NAME, Release_Date, electorcount) from the province's ArcGIS service.

---

## 0. Headline findings

1. **Open North Represent** (https://represent.opennorth.ca) is the only single API that returns MP + MLA + (HRM/CBRM) council for a point, with e-mail, photo and offices[]. VERIFIED. But it is **stale in ways that matter**:
   - Its NS legislature set is bound to the *2019* provincial boundary set (55 districts). The province now has **56 districts**: `Chéticamp-Margarees-Pleasant Bay` (ED_NO 56, released April 9, 2026; MLA Claude Bourgeois, by-election June 23, 2026) is **absent** from Represent.
   - Its House of Commons set lists Chris d'Entremont as **Conservative**; ourcommons.ca shows **Liberal** (caucus role from 2025-11-04). His Kingston office address is also outdated in Represent.
   - Represent's NS MLA `offices[].postal` field is a scraper artefact (`"Phone:\n\nE-mail:"`) — no addresses.
   - Municipal coverage in NS = **Halifax Regional Council and Cape Breton Regional Council only** (plus boundary polygons for 27 other NS municipalities, 2017 vintage, without representatives).
   - No data licence is published for the representative data; the API is "free up to 60 requests per minute". Using it live would send the user's coordinates to a third party (Open North), which the privacy contract forbids.
2. **Authoritative per-level sources exist and are scrapeable**:
   - Federal: ourcommons.ca search XML/CSV (VERIFIED: names, constituency, caucus, dates — **no contact fields**); contact details are only on each member's HTML page (`/Members/en/<slug>(<PersonId>)`).
   - Provincial: nslegislature.ca `/members/profiles` (Drupal view, 56 rows, VERIFIED) + per-profile HTML with constituency office civic/mailing address, phone, e-mail, caucus office. `robots.txt` allows, Crawl-delay 10. No JSON/XML feed.
   - HRM: halifax.ca district pages (email + phone) VERIFIED; ArcGIS `Who_Is_My_Councillor_WFL1` layer has **only** `DIST_ID`, `DISTNAME`, `COUNCILLOR` (no contact) VERIFIED.
   - CBRM: cbrm.ns.ca per-district pages with e-mail + phone VERIFIED (13 districts+mayor).
   - Province-wide municipal heads: **no open dataset on data.novascotia.ca** (catalog searched, VERIFIED negative). NSFM's Membership Directory regional pages list Mayor/Warden *names + website* for every municipal unit (VERIFIED for Valley and Cape Breton-Strait regions) — no phones/e-mails except NSFM board members. Municipal Affairs' old `/dma/directory/` is gone (404 VERIFIED).
   - CSAP: csap.ca/le-csap/gouvernance/conseil lists 13 elected members with circonscription name, `@csap.ca` e-mail and phone (VERIFIED). **No public polygon layer for CSAP circonscriptions was found**; the province's "School Board Zones" datasets are 2020 board-zone polygons, not electoral circonscriptions.
3. **Recommended architecture**: ship a **static, dated directory snapshot** keyed by district id, generated by a repo script from the official sources above (not from Represent), with a `checked_date` per record and a visible "verify on the official page" link. Details in section 9.

### 1.6 Terms, rate limits, attribution, freshness
- API reference (https://represent.opennorth.ca/api/), VERIFIED text: "Represent is free up to 60 requests per minute (86,400 queries/day). If you need to make more queries, contact us; otherwise, you may get HTTP 503 errors."

Boundary shapefiles: "Open North has permission to redistribute all shapefiles in this repository … In some cases, you will not have permission to redistribute the shapefile" (represent-canada-data README). - Freshness: not exposed per representative set. Observed staleness: HoC party for d'Entremont (stale since 2025-11-04), Kingston office address, missing 56th NS district (April/June 2026). Boundary-set `last_updated` values above.

## 2. Federal — House of Commons open data — VERIFIED

- Current members, all provinces: `https://www.ourcommons.ca/members/en/search/xml` (338 `<MemberOfParliament>` on 2026-09-12; 343 seats, so 5 vacancies) and `/members/en/search/csv`. Filter: `?province=NS` → 11 members (VERIFIED).
- Fields (XML): `PersonId, PersonShortHonorific, PersonOfficialFirstName, PersonOfficialLastName, ConstituencyName, ConstituencyProvinceTerritoryName, CaucusShortName, FromDateTime, ToDateTime`. CSV header: `Person ID, Honorific Title, First Name, Last Name, Constituency, Province / Territory, Political Affiliation, Start Date, End Date`. **No e-mail, phone or office fields.** No FED numeric id either — join to polygons by `ConstituencyName` (em-dash names, e.g. `Acadie—Annapolis`) or via `PersonId`.
- Per-member roles XML: `https://www.ourcommons.ca/Members/en/<slug>(<PersonId>)/xml` — caucus history, committees; still no contact.
- Contact details are only in the member HTML page (`.../Members/en/chris-dentremont(49344)`), section "Contact Details": e-mail, website, Hill Office (tel/fax), "Constituency Offices" blocks (label, address, telephone, fax). Parsed sample in `geo/reps_directory_sample.json`. Photo URL pattern: `https://www.ourcommons.ca/Content/Parliamentarians/Images/OfficialMPPhotos/45/<Last><First>_<Party>.jpg`.
- The 11 NS MPs (search XML, 2026-09-12): Battiste (Cape Breton—Canso—Antigonish), Blois (Kings—Hants), Clark (Sackville—Bedford—Preston), **d'Entremont (Acadie—Annapolis, Liberal)**, Diab (Halifax West), Fancy (South Shore—St. Margarets), Fisher (Dartmouth—Cole Harbour), Fraser (Central Nova), Hirtle (Cumberland—Colchester), Kelloway (Sydney—Glace Bay), Miedema (Halifax). All Liberal caucus; all FromDateTime 2025-04-28.
- robots.txt: disallows `/Search/`, `/PublicationSearch/`, `/Embed/`, `/ParlDataWidgets/`, `/ErrorPage/` only. `/members/en/search/xml` is not disallowed.
- Licence (VERIFIED text on https://www.ourcommons.ca/en/open-data and /en/important-notices): Open Data page — "Open data is defined as structured data that is machine-readable, freely shared, used and built on without restrictions." Important Notices "Copyrights" — "Permission to reproduce—in whole or in part—or to otherwise use the content of this website may be sought from [the House]"; the "Speaker's Permission" grants reproduction of *proceedings* provided it is accurate, not presented as official, and not "for commercial purpose of financial gain". No formal OGL. Practical reading: the open-data XML/CSV is intended for reuse; contact details scraped from member pages sit under the general copyright notice. Keep a source link and "not official" wording.

## 7. Data-quality traps observed
- Represent HoC `offices[0].fax` equals the tel for d'Entremont ([phone on official page]) while ourcommons.ca shows fax [phone on official page] — scraper error.
- Represent NS `postal` is literally "Phone:\n\nE-mail:" (sometimes with "Fax: …" or "Toll free: …" inside) — parse tel/fax from it if needed, never display it.
- nslegislature listing names contain double spaces and trailing spaces ("Bowlby,  David", "Digby-Annapolis ").
- HoC CSV dates are locale-formatted ("4/28/2025 12:00:00 a.m." with U+202F); prefer the XML.
- Several MLAs publish gmail/outlook constituency addresses; these are the official published contacts, not personal leaks, but display them exactly as published.
- Municipal directories publish councillor phones without saying office/home. Store as `directory_listed_phone` with a caveat, and always show the municipal office number.
- Federal riding ids differ by representation order (Acadie—Annapolis 12001 in 2023 RO vs West Nova 12011 earlier). Key federal records by 2023-RO FED id.

## 9. Recommended architecture

**Ship a static, dated directory snapshot; do not call Represent (or any third party) from the browser.**

Why:
1. Privacy contract: the app must not send browser location off-device. Represent's point endpoint requires the coordinate. A static directory keyed by district id lets the existing local point-in-polygon do the lookup with zero network.
2. Represent is demonstrably stale (party change Nov 2025, 56th district 2026) and has no data licence, no `last_updated`, and only HRM/CBRM municipal coverage. The official sources are the ground truth anyway.
3. Contact data changes on election dates and occasional office moves — a monthly/quarterly regenerated snapshot is adequate if every card shows `checked_date` and links to the official page.

Proposed shape (one JSON per level, generated by a repo script; ~60–300 records each):
```json
{"generated": "2026-09-12", "level": "provincial", "boundary_vintage": "ED2026 (nsgiwa BND_ElectoralBoundaries_UT83/4)",
 "records": {"56": {"district_name": "Chéticamp-Margarees-Pleasant Bay", "name": "Claude Bourgeois", "party": "PC",
   "email": "[personal-domain e-mail on official profile]", "offices": [...], "page": "https://nslegislature.ca/members/profiles/claude-bourgeois",
   "source": "https://nslegislature.ca/members/profiles", "checked": "2026-09-12", "photo": null}}}
```
Keys: federal → 2023-RO FED id ("12001"); provincial → `ED_NO` ("01".."56"); HRM → `DIST_ID` (1–16); CBRM → district number (1–12); other municipalities → `<csd_id>:<district>` only where polygons and a verified council page exist, else `<csd_id>` with head-of-council only (from the municipality's own site, NSFM as a cross-check); CSAP → circonscription name, flagged "approximate — no official polygon".

Generator sources: ourcommons.ca search XML + member HTML; nslegislature.ca listing + profile HTML (respect Crawl-delay 10); halifax.ca district pages; cbrm.ns.ca district pages; per-municipality pages; csap.ca conseil page. Store the fetched HTML hashes so a diff triggers review. Keep Represent only as an offline cross-check in the generator, never as a runtime dependency.

UI evidence rules: show the level, district name + id, official name, party (federal/provincial only), official e-mail, office phone(s) and address exactly as published, "checked YYYY-MM-DD", and a link to the official page; render municipal `directory_listed_phone` with its caveat; label CSAP as approximate; if a district id has no record (e.g. vacancy, new district), show "no record in snapshot dated …" rather than falling back to a stale name.

Polygon vintage must match the directory: provincial polygons must be the 56-district ED2026 set (Inverness was re-cut on April 9, 2026); federal must be the 2023 Representation Order; HRM the 2024 NSUARB districts; other municipal polling districts (2017 open-data vintage) need a boundary-review check before any councillor is asserted.
