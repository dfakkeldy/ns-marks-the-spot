# Claude Code Guidelines for NS Marks The Spot

@AGENTS.md

`AGENTS.md` is the canonical repository guide. The current product focus is the
browser map under `web/`; apply native Apple guidance only when a task actually
touches the native app.

Explain project-specific architectural or evidence-boundary decisions in plain
language, especially when they affect map accuracy, provenance, licensing,
privacy, or what a user may safely conclude from a layer.
